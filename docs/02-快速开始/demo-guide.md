# Demo 使用指南

本页介绍 RAG Tech Docs 在线 Demo 的界面功能与操作流程。你可以通过本地启动的服务访问，也可以使用我们提供的在线体验地址。

## 访问 Demo

- **本地访问**：启动前后端服务后，访问 `http://localhost:3000/demo`（或你自定义的 Demo 页面路径）。
- **在线体验**：访问 [https://your-demo-url.com](https://your-demo-url.com)（替换为你的实际部署地址）。

## 界面概览

Demo 界面主要分为三个区域：

1. **左侧导航栏**：文档列表、上传入口、会话历史。
2. **中间对话区**：显示用户提问和 AI 回答，支持流式输出。
3. **右侧引用区**：展示 AI 回答所引用的原始文档片段。

## 核心操作流程

### 1. 上传文档

点击左侧导航栏的 **“上传文档”** 按钮，选择本地文件（支持 PDF、Markdown、TXT）。

- **文件大小限制**：单文件不超过 10MB。
- **上传后处理**：系统会自动进行解析、分块和向量化，处理时间取决于文件大小和模型速度。
- **查看状态**：上传成功后，文档会出现在左侧列表中，并显示“已索引”状态。

### 2. 发起提问

在中间的输入框中输入你的问题，例如：

> “这份文档主要讲了什么？”

点击发送或按 `Enter` 键。系统会：

1. 将问题向量化。
2. 在向量库中检索最相关的文档片段。
3. 将上下文和问题发给大模型。
4. 流式返回回答。

### 3. 查看引用溯源

AI 回答下方会附带 **“参考来源”** 卡片，显示引用的文档名称和片段内容。点击卡片可以展开查看完整片段，方便核实信息的准确性。

### 4. 管理知识库

- **查看文档**：左侧列表展示所有已上传的文档。
- **删除文档**：点击文档右侧的删除图标，系统会同时删除向量库中的对应数据。
- **重新索引**：如果文档更新，可以删除后重新上传，或使用增量更新功能（规划中）。

### 5. 多轮对话

Demo 支持携带历史上下文。你可以连续提问，例如：

> 用户：这份文档提到了哪些技术栈？  
> AI：它提到了 FastAPI、Chroma 和 OpenAI……  
> 用户：其中 Chroma 是用来做什么的？  
> AI：Chroma 是向量数据库，用于存储文档向量……

点击左上角的 **“新建会话”** 可以清空上下文，开始新一轮对话。

## 高级设置

在 Demo 界面的右上角，你可以调整：

- **模型选择**：切换不同的 LLM（如 GPT-3.5、GPT-4）。
- **Top-K 检索数量**：调整检索返回的文档片段数量（默认 3）。
- **流式输出开关**：开启或关闭逐字输出效果。

## 常见问题

| 问题 | 可能原因 | 解决方案 |
| :--- | :--- | :--- |
| 上传失败 | 文件格式不支持 | 确认是 PDF/MD/TXT 格式 |
| 回答“我不知道” | 检索不到相关内容 | 尝试换一种问法，或上传更相关的文档 |
| 回答速度慢 | 模型响应慢 | 切换更快的模型，或减少 Top-K |
| 引用为空 | 未开启引用溯源 | 在设置中开启“显示引用” |
