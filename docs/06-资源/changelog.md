# 更新日志

本页记录 RAG Tech Docs 的所有版本变更。版本号遵循 [语义化版本 (SemVer)](https://semver.org/lang/zh-CN/) 规范。

## [Unreleased]

### 新增
- 规划中：支持更多向量数据库（Qdrant、Weaviate）。
- 规划中：支持多模态文档解析（图片、表格）。
- 规划中：提供 Web UI 管理后台。

## [v1.0.0] - 2026-10-13

这是 RAG Tech Docs 的首个正式版本。

### 新增
- 🎉 完成 RAG 技术文档站点的整体框架搭建（基于 Docusaurus 3.x）。
- 📚 文档遵循 Diátaxis 框架，包含概览、快速开始、指南、API 参考、原理与最佳实践、资源、关于七大模块。
- 🔌 提供完整的 API 参考文档，涵盖文档管理、问答对话、系统接口。
- 🧠 详细讲解了 RAG 流程、分块策略与效果评估方法。
- 🛠️ 提供 Python FastAPI 后端 Demo 的规划与设计。
- 🚀 配置了 GitHub Actions 自动部署到 GitHub Pages。

### 优化
- 优化了首页导航卡片，采用现代化卡片式布局。
- 导航栏与页脚与文档目录结构完全对齐。
- 启用了 Mermaid 图表支持，方便绘制架构图与流程图。

### 修复
- 修复了初始化时默认教程文件（`tutorial-basics`、`tutorial-extras`）残留导致的编译报错。
- 修复了侧边栏文档 ID 与文件夹命名不一致的问题。

### 文档
- 完成 `01-概览` 至 `06-资源` 所有核心模块的初稿撰写。
