# 功能特性

RAG Tech Docs 旨在提供一个**开箱即用、易于扩展**的 RAG 问答解决方案。以下是本项目的核心功能特性。

## 文档处理能力

- 📄 **多格式支持**：支持 PDF、Markdown、TXT 等常见文档格式的解析与导入。
- ✂️ **智能分块**：支持固定长度、重叠分块、按语义分块等多种策略，平衡检索精度与上下文完整性。
- 🔄 **增量更新**：支持文档的增删改查，向量库自动同步更新，无需全量重建索引。
- 📊 **元数据过滤**：支持按文件名、上传时间等元数据过滤检索范围。

## 检索与问答能力

- 🔍 **向量检索**：基于语义相似度，精准召回与问题最相关的文档片段。
- 🎯 **重排优化**：可选接入 Rerank 模型，对初步检索结果进行精排，显著提升回答质量。
- 🧠 **多模型支持**：兼容 OpenAI 接口规范，支持 GPT-3.5、GPT-4 以及通义千问、文心一言等国内大模型。
- 💬 **多轮对话**：支持携带历史对话上下文，实现连贯的多轮问答。
- 🌊 **流式输出**：支持 SSE 流式返回，逐字显示回答，提升交互体验。
- 📚 **引用溯源**：回答中自动附带参考的文档片段来源，方便用户核实。

## 开发者友好

- 🚀 **RESTful API**：提供标准 HTTP 接口，方便集成到你的业务系统中。
- 📖 **自动生成 API 文档**：基于 FastAPI，自动生成 Swagger UI 和 OpenAPI 规范。
- 🔐 **鉴权机制**：支持 Bearer Token 认证，保护你的 API 安全。
- 🐳 **容器化部署**：提供 Dockerfile 和 docker-compose 配置，一键部署。
- 📝 **标准技术文档**：遵循 Diátaxis 框架，提供教程、指南、参考、解释四类文档。

## 前端与演示

- 🎨 **在线 Demo**：提供交互式 Web 界面，支持文档上传、问答对话、引用查看。
- 🌙 **深色模式**：文档站点与 Demo 界面均支持深色模式。
- 📱 **响应式设计**：适配桌面端与移动端。

## 与纯 LLM 方案的对比

| 对比项 | 纯 LLM 直接问答 | RAG Tech Docs |
| :--- | :--- | :--- |
| 私有数据 | 不支持，容易产生幻觉 | 支持，基于检索结果回答 |
| 知识时效 | 受限于训练数据时间 | 实时更新，上传即可用 |
| 数据隐私 | 数据需上传至第三方 | 数据存储在本地向量库 |
| 回答溯源 | 无法提供来源 | 提供引用片段，可核实 |
| 成本 | 微调成本高 | 无需微调，按 Token 计费 |
