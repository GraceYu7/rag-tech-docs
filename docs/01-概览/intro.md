# RAG Tech Docs 项目介绍

欢迎来到 **RAG Tech Docs**！这是一个面向开发者的检索增强生成（Retrieval-Augmented Generation, RAG）技术文档与实战演示项目。

本项目旨在提供一个开箱即用的 RAG 问答系统，并配合一套标准、清晰的技术文档，帮助开发者快速理解 RAG 的核心原理，并能够将其集成到自己的业务中。

## 为什么需要 RAG？

大语言模型（LLM）虽然强大，但在处理私有数据或特定领域知识时，往往会遇到以下问题：
- **知识幻觉**：模型可能编造不存在的事实。
- **时效性差**：模型的知识受限于训练数据的时间。
- **数据隐私**：无法直接将敏感数据用于模型微调。

RAG（检索增强生成）通过“先检索，后生成”的方式，有效解决了上述问题。它将你的私有文档转化为向量存入数据库，在提问时先检索相关内容，再交由大模型生成准确的回答。

## 核心特性

- 📄 **多格式文档解析**：支持 PDF、Markdown、TXT 等常见格式。
- 🔍 **高效向量检索**：支持主流向量数据库（如 Chroma, Milvus）。
- 🧠 **智能问答**：支持接入 OpenAI、国产大模型（如通义千问、文心一言）。
- 🎨 **开箱即用**：提供完整的 FastAPI 后端接口与 React 前端 Demo。
- 📚 **标准文档**：遵循 Diátaxis 框架，提供教程、指南、API 参考与原理讲解。

## 系统架构

本项目的 RAG 流程如下：

1. **数据导入**：解析文档 -> 分块（Chunking） -> 向量化（Embedding）。
2. **向量存储**：将向量存入向量数据库。
3. **检索**：用户提问时，将问题向量化并检索最相似的文档块。
4. **生成**：将检索到的上下文与问题组合，交由 LLM 生成最终回答。
